How this demo was made

Each of 48 fictional comments has a short and an expanded version. Each wave gets one version per comment, with all eight themes equally represented. The demo computes cosine similarities from precomputed BGE embeddings. It randomly reassigns the answers within each five-word band without replacement and recalculates the difference between waves 400 times.

The middle 95% describes the spread of simulated changes in this example. The result depends on the comments, length bands and embedding model.

Based on Fengming Liu’s preprint on embedding cosine and text length.
