Can comment length move a similarity score?

If survey answers look more alike in one wave than another, see how much of that change you can reproduce by keeping each wave’s mix of short and long answers.

Two fictional survey waves

Both waves contain the same 48 comments, six on each of eight themes. Wave 2 has more of them written out with an extra sentence of detail.

The score averages cosine similarity across all pairs of answers within a wave. Higher values mean the embeddings are closer together.

Try this on your own survey

Take answers to the same question across waves and rerun the shuffle with your existing embeddings. If the shuffle repeatedly produces a similar change, compare answers of similar length and read a sample before drawing conclusions about what people are saying.

A result inside the range means length could explain the change. It doesn’t show the themes stayed the same. With a few dozen answers per wave the range is wide, so a real shift in themes can sit inside it too.

How this demo was made

Each of 48 fictional comments has a short and an expanded version. Each wave gets one version per comment, with all eight themes equally represented. The demo computes cosine similarities from precomputed BGE embeddings. It uses BGE because Liu found it reacts strongly to length in Reddit comments, which makes the effect easy to see. Across both waves, two expanded answers on different themes average 0.585, higher than two short answers on the same theme (0.573). Another model, or other text, can show a smaller effect or one in the opposite direction. The demo randomly reassigns the answers within each five-word band without replacement and recalculates the difference between waves 400 times.

The middle 95% describes the spread of simulated changes in this example. The result depends on the comments, length bands and embedding model. Each run draws 400 new shuffles, so the range shifts slightly from run to run.

Based on Fengming Liu’s preprint on embedding cosine and text length. Source code and data script on GitHub.
